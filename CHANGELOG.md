# Changelog

## 1.1.0 — version code 2

- Updated Android build configuration to compile and target SDK 37.
- Added adaptive Material 3 appearance, system theme support and additional color customization.
- Updated floating button and panel appearance live, including size, shape and transparency settings.
- Refined grouped card corners, spacing, navigation and RTL overlay transitions.
- Improved gallery thumbnails, image viewing and share/delete controls.
- Corrected duplicate Shizuku permission declaration and LSPosed capture compatibility.
- Removed developer manager-launch and diagnostic-copy actions from the capture engine screen.
- Added manual GitHub Actions output selection for APK and AAB builds.

## 1.0 — version code 1

Initial release with floating drawing tools and multiple screenshot engines.
